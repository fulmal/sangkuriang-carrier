DevOps Officer

Deploy and manage cloud & on-premise infrastructure, keep production healthy and secure.

  • AWS / Azure / GCP
  • Docker
  • Kubernetes

Key Responsibilities

  • Deploy and manage server infrastructure (cloud & on-premise)
  • Monitor system performance and troubleshoot production issues
  • Implement security best practices across infrastructure
  • Collaborate with developers to streamline deployment

Requirements

  • Bachelor's in Computer Science, Engineering, or related field
  • Experience with AWS/Azure/GCP, Docker, and Kubernetes
  • Proficient in scripting (Python, Bash) and config tools (Ansible, Chef, Puppet)
  • Understanding of networking, databases, and data platforms
  • Fresh graduates are welcome

Fullstack Developer

Build scalable backend services and responsive web frontends from wireframes and SRS.

  • React / Next.js
  • Node.js
  • Java / Python

Key Responsibilities

  • Build scalable backend services and responsive web frontends
  • Maintain, troubleshoot, and enhance existing applications

  • CI/CD, GraphQL, or Kubernetes experience is a plus
  • Fresh graduates are welcome

System Analyst

Turn business processes into system specifications and bridge clients with the dev team.

  • BRD & Use Cases
  • SQL & API
  • Wireframes

Key Responsibilities

  • Analyze business processes and translate them into system specifications
  • Act as liaison between client stakeholders and the development team
  • Create BRD, functional specs, use cases, and process flowcharts
  • Coordinate UAT and ensure all changes are documented

Requirements

  • Experience as System Analyst, Business Analyst, or similar role
  • Skilled in requirements gathering and system documentation
  • Understanding of SDLC, SQL, and API integration (JSON, XML)
  • Able to create wireframes and mockups
  • Knowledge of LLM, RAG, ontology, or Mandarin is a plus
  • Fresh graduates are welcome

Project Management Officer

Plan scope, schedule, resources and risks — lead cross-divisional teams to quality delivery.

  • Agile / Scrum
  • Jira & MS Project
  • Leadership

Key Responsibilities

  • Develop project plans covering scope, schedule, resources, risks, and KPIs
  • Lead cross-divisional teams and monitor project progress
  • Manage scope changes, risks, and project documentation
  • Deliver status reports and ensure quality deliverables

Requirements

  • Bachelor's in IS, Computer Science, Industrial Engineering, Management, or related
  • Understanding of SDLC and Waterfall/Agile/Scrum
  • Proficient in PM tools (Jira, MS Project, Trello, ClickUp, Notion)
  • Strong leadership and communication in Bahasa Indonesia & English
  • CAPM/PMP/Scrum Master certification or Mandarin skills is a plus
  • Willing to travel; fresh graduates welcome

IT Account Manager / Sales

Be the main PIC for clients, recommend the right IT solutions and grow long-term relationships.

  • Negotiation
  • Presentation
  • Client relations

Key Responsibilities

  • Serve as main PIC and build long-term client relationships
